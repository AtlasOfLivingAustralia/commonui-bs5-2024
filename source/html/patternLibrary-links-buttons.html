ALA pattern library for Bootstrap 5 sites using the 2024 design system

Be aware that styles can differ between "mobile" (<992px browser width) and "desktop".

Also keep dark and light mode in mind: you can use the mode selector in the header.

See the Bootstrap 5 button docs for more details on usage.

The normal button used in this design should be primary outline.
